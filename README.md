# Pac-Man on AWS EKS Auto Mode

DevSecOps final project that deploys a containerized Pac-Man application and MongoDB on **Amazon EKS Auto Mode**.

The application is based on the supplied Pac-Man project. This repository focuses on the DevSecOps layer: Infrastructure as Code, Kubernetes deployment, CI/CD, persistent storage, monitoring, security controls, automated launch and complete teardown.
